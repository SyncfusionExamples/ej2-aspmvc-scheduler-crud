# ej2-aspmvc-scheduler-crud

## Overview

This is a quick start ASP.NET MVC project that demonstrates how to perform CRUD (Create, Read, Update, Delete) operations using the Syncfusion EJ2 Scheduler component with URL adaptor for seamless backend communication. It provides a complete example for managing events and schedules in an ASP.NET MVC application.

## Features

- **CRUD Operations:** Complete implementation of Create, Read, Update, and Delete operations for scheduler events
- **URL Adaptor:** Demonstrates proper usage of URL adaptor for backend communication
- **Event Management:** Manage appointments and events efficiently
- **ASP.NET MVC Integration:** Showcases best practices for Syncfusion EJ2 Scheduler in ASP.NET MVC framework
- **Data Binding:** Seamless data binding between frontend and backend

## Prerequisites

- Visual Studio 2022 or later
- .NET Framework 4.5 or higher
- NuGet Package Manager

## Project Structure

This project includes:
- Controllers for handling CRUD operations
- Views with Syncfusion EJ2 Scheduler component
- Models for event data management
- Configuration for URL adaptor endpoints

## How to Run the Project

1. Checkout this project to a location in your disk
2. Open the solution file using Visual Studio 2022
3. Restore the NuGet packages by rebuilding the solution
4. Build and run the project
5. The application will launch in your default browser

## Configuration

Configure the scheduler by:
- Setting up controller endpoints for CRUD operations
- Configuring the URL adaptor with appropriate service endpoints
- Customizing event properties and view settings as needed
